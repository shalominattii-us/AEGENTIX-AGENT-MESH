# Sovereign Claw Commands

## Status
`/status` — Fleet status, cabinet roster, treasury overview

## Cabinet
`/cabinet` — List all 8 advisors
`/consult [name]` — Ask specific advisor (e.g., `/consult Vigil`)

## Venues
`/venues` — List 8 diplomatic chambers
`/gate [venue]` — Check entry requirements

## Treasury
`/treasury` — TSL allocation breakdown
`/balance` — ESC/XRP summary

## Executive
`/order [category]` — Draft executive order template
`/null` — Check NULL protocol status

## Memory
`/remember [fact]` — Store persistent fact
`/recall [topic]` — Retrieve stored facts

## Help
`/help` — Full command list
`/about` — Sovereign manifesto
