## ⚡ Quickstart & Local Execution

### Prerequisites
- Node.js >= 20.x
- npm >= 10.x
- Git >= 2.34

### Installation & Run
```bash
# Clone the repository with all submodules
git clone --recursive https://github.com/shalominattii-us/Aegentix.git
cd Aegentix

# Install dependencies
npm install

# Start development full-stack server
npm run dev
# Server listening on http://localhost:3000
```

### Build & Verification
```bash
# Lint with strict TypeScript checks
npm run lint

# Build full-stack bundle (Vite + Node/Express)
npm run build
```
